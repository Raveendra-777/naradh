
## Naradh

A simple command-line tool.

---

## Installation (Linux)

```bash
git clone https://github.com/yourusername/naradh.git
cd naradh
chmod +x naradh.py
mv naradh.py naradh
sudo cp naradh /usr/local/bin/
```

---

## Usage

```bash
naradh
```

---

## Notes

* Make sure Python 3 is installed
* if not install by this command
```bash
sudo apt install python3
```
* `/usr/local/bin` allows running the command globally
* If `naradh` doesn’t work, restart terminal or run:

  ```bash
  hash -r
  ```
